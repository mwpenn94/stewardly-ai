1. Log in to Marketplace Developer Portal (marketplace.gohighlevel.com)
2. Click Testing in top nav
3. Click + Create App Test Account
4. Enter Agency Name + Password
5. Account provisioned immediately
6. Active for 6 months
7. Includes Enterprise features for testing
8. Can generate Private Integration Tokens (PITs) for API testing

Need: GHL Marketplace Developer account to create sandbox

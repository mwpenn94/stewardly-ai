# Comparable Platform Research Notes

## RightCapital (2025 Features)

Key features we should match or exceed:

1. **Tax Analyzer** — OCR upload of tax returns, auto-extract data, model tax-smart changes, compare scenarios. We have TaxPlanning.tsx but need OCR upload capability.

2. **Smart Import** — Revolutionizing data import. We have Import Data page but need to verify it matches this level.

3. **Business Owner Planning** — Expanded modules. We have BusinessValuation, BusinessIncome, OwnerComp pages.

4. **Client Portal** — Client-facing mobile app with account aggregation. We have client dashboard but need to verify portal experience.

5. **Snapshot** — One-page plan summaries, customizable. We need to check if our financial planning has a summary/snapshot view.

6. **Prospecting Tools** — Lead generation features. We have LeadPipeline.

7. **Reporting Flexibility** — Customizable reports. Need to check our reporting capabilities.

## eMoney Advisor

Key features:
1. **Client Portal** — Industry-leading, all finances in one place, account aggregation
2. **Guided Onboarding** — We have OnboardingFlow, OnboardingTour, OnboardingChecklist
3. **Data Migration Support** — We have Import Data
4. **94% advisor satisfaction** — benchmark for UX quality

## Orion Advisor

Key features:
1. **Advisor Portal** — Personalized proposals, BeFi-driven financial planning
2. **Insight Dashboard** — Account overview, monthly performance
3. **Scalable for solo advisors to top RIAs**
4. **MassMutual integration** — All-in-one wealthtech platform
